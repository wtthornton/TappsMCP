## Objective

Cut the TappsMCP session floor roughly in half and give long sessions a rotation
mechanism, so agents in this repo and its 24 consumer repos stop living above 150K
context.

## Loop

- **State:** read the last handoff · `uv run tapps-mcp memory search --query "context efficiency floor rotation"` for prior attempts · current VAL table · last measurement JSON. Never re-read a file already summarized in state.
- **Decide:** pick the lowest-numbered sub-goal not yet verified green. Never skip ahead; never invent decide work.
- **Execute:** the committed mechanism + tier from the Plane map. Serial for edits.
- **Verify (independent):** spawn a **fresh-context verifier subagent (frontier tier)** prompted to **refute** the sub-goal's proof. It re-runs `scripts/measure_context_floor.py`, the tests, and the CLI itself — it does not trust the executor's paste. Default to *not done* on any doubt. For SG5, three verifiers with the diverse lenses above; majority rules.
- **On fail (expected-fail fix loop):** record a structured handoff → scope a narrow fix sub-goal against the verifier's actionable gaps → re-execute → re-verify. **≤3 validation rounds per sub-goal**, then escalate once, then stop with a diagnosis. Never weaken a VAL to go green.
- **Record:** completed · undone · commands + exit codes · issues · procedures followed? · failure-and-why → `tapps_handoff_save` at each sub-goal boundary.
- **Context hygiene:** this prompt is *about* context cost — practice it. Prune stale reads each iteration; targeted `grep` over full re-`Read`; carry the measurement JSON forward as state instead of re-deriving it. Rotate the session yourself at ~110K rather than waiting for compaction.
- **Repeat or stop:** loop until Done-when holds. Caps: **21 iterations** AND **~600K output tokens**.

## Guardrails

- Termination: the Done-when above; caps 21 iterations AND ~600K output tokens.
- **Caps must not fire on correct behavior:** VAL-6 missing 16,000 by a small margin
  *with VAL-13 green* is a reportable near-miss, not a failure requiring more cutting.
  A verified-correct residual is an acceptable terminal state — say so and stop.
- Validation contract precedes execution; coverage complete; never rewritten to match
  an implementation that came out differently.
- Independent verification, creator ≠ verifier, ground-truth artifacts only.
- **No fan-out of coupled coding.** Edits are serial, one workstream branch at a time.
- Context hygiene per the Loop.
- Scope: **`/home/wtthornton/code/tapps-mcp` only.** Reads may go fleet-wide; the 24
  consumer repos are **not** touched by this run — they refresh later via their own
  `tapps_upgrade`, which is out of scope here (`.claude/rules/agent-scope.md`).
- Edit **template sources** (`pipeline/platform_*.py`), never deployed `.claude/` copies.
- Any template edit → `python3 scripts/bump-versions.py --patch` in the same commit.
  Never hand-edit a version field.
- Memory: recall at start, record a structured handoff at every sub-goal boundary.
- Harness compatibility per the SG0 table — especially the **deploy-lag** and
  **self-modification** hazards.
- Discipline: root-cause not workarounds; **no green-by-suppression** — never `# noqa`,
  `# type: ignore`, skip a test, or delete a parameter to hit a number; right-sized;
  durable; match repo conventions; no scope creep.
- **`tapps_explore` is explicitly deferred.** Do not build it. If the Bash bucket still
  looks large after SG4, record the measurement and stop — that decision is the user's.

## Autonomy

- Act on every reversible, in-scope step. No "should I proceed?" checkpoints.
- Irreversible/outward → produce the reversible precursor (draft PR, staged diff) and

## Failure handling

- On failed verify: diagnose (actual error + state + brain recall) → hypothesis → fix →
  retry with *something changed*. Never re-run the same action on the same error.
- ≤3 distinct strategies per sub-goal → escalate once → stop with a concise diagnosis.
- First verify failing is **expected**, not a crisis. Scope a narrow fix; do not reopen
  the workstream or rewrite the contract.
